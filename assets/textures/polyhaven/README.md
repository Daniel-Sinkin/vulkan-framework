# Poly Haven Texture Assets

Vendored on 2026-05-16 for the `ds_vk_basic_app` material texture smoke test.

All assets in this directory are from Poly Haven and marked CC0 on their asset
pages.

- `concrete_floor_diff_1k.jpg`: diffuse map from
  <https://polyhaven.com/a/concrete_floor>
- `wood_table_001_diff_1k.png`: diffuse map from
  <https://polyhaven.com/a/wood_table_001>

The framework currently consumes these as base-color/albedo textures. Additional
PBR maps from the same assets can be added later once the material config grows
normal/roughness/metallic texture slots.
